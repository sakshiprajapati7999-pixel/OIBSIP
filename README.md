
# Voice Assistant using Python

## Project Overview
This project is a simple voice assistant developed using Python. It listens to voice commands and responds through speech.

## Features
- Voice greeting
- Current time announcement
- Current date announcement
- Open Google using voice commands
- Search Google using voice commands
- Text-to-speech responses
- Error handling for microphone and speech recognition

## Technologies Used
- Python 3.10
- SpeechRecognition
- pyttsx3
- PyAudio
- datetime
- webbrowser

## Installation
Install the required libraries:

```bash
python -m pip install SpeechRecognition pyttsx3 PyAudio
```

## How to Run
1. Download or clone this project.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python voice_assistant.py
```

5. Allow microphone access and speak clearly in English.

## Voice Commands
- Hello
- What is the time?
- What is today's date?
- Open Google
- Search
- Stop
